# 战术助手运行说明

在项目目录运行 `start-tactics.ps1`，打开 http://127.0.0.1:8790/assistant 。资料库首页也有入口，`/solver` 仍是独立实验室。

应用复用 `.env` 的既有模型配置，不打印密钥。新增视频渠道依赖见 `requirements-lineup-research.txt`；只需安装到项目 `.venv`。不要从 PyPI 安装同名 Agent-Reach，使用固定的上游 GitHub 版本。

网页支持单颗道具和整套 Nuke 战术，填写人数、动作限制及可选逐人库存。来源最低装备按钮只填教学示例，不代表当前玩家实况。未勾选状态按未知处理。

每次任务使用现有 Eregion AgentLoop：需求 → 本地检索 → 缺口研究 → 适配和逐人整理 → 显式结束。Agent-Reach 作为能力路由：YouTube 使用 yt-dlp；Bilibili 使用 bili-cli；网页使用 Jina Reader，通用搜索另有公开 RSS 后备。这里只启用公开只读操作，不运行全局安装、不读取浏览器 Cookie、不进行音视频下载和音频转写。

任务保存在 `outputs/lineup-research/runs/<id>/`；按钮支持取消与同一需求恢复。取消会阻止后续调用并丢弃迟到的模型结果，已发送的请求可能继续到超时或产生用量。恢复不重置调用预算；修改需求请新建任务。

缓存位于 `data/knowledge/lineups/cache/`，成功资料通常 7 天，失败状态 5 分钟；预算记录缓存命中。结构化迁移在 `data/knowledge/lineups/nuke.json`，原六条资料的全部历史字段留在 `legacy`，原始文件和实验结果保留。带证据的新字段写入独立的 `enriched` 文件。

页面的“已读取”只指实际取得相应文字，不能代表看过视频画面或实投通过。Cookie 提示页和脚本空壳为证据不足，访问拦截为不可访问，搜索摘要永远是线索。没有坐标仍可打开原视频；当前未支持将网页控制台命令作为可复制指令。

单颗上限：3 次搜索、8 次读取、6 次模型调用、180 秒研究墙钟；整套上限：12 / 24 / 12 次、360 秒。单次模型输出最多 1800 tokens，整任务输入保守预留最多 180000 单位。CLI 的底层 HTTP 次数无法精确观测，另有超时、重试数和输出体积限制，不将逻辑调用数伪装为精确网络包数。费用没有可靠价格表时保持未知。
