# Agentic RAG 新版工作台整合报告

日期：2026-10-15

## 结果

前一版错误地把已弃用的独立助手页作为交付入口。本轮已将 Agentic RAG 并入当前 Mission Control 工作台。

入口：`http://127.0.0.1:8790/demos?view=research`，主导航“07 战术助手”。

## 界面与交互

- 使用新版已有的 Mission Control 主题、字体、黑红配色、面板边角、表单控件和主导航选中态。
- 左侧研究需求，右侧研究结果；桌面布局左右独立滚动，窄屏改为上下排列。
- 复用顶部模型设置及语言切换，补充新入口主要控件的英文文案；来源原文与模型生成内容不自动翻译。
- 保留战术资料问答、单颗道具教学、Nuke 全套教学入口，以及已有启动、取消、恢复、引用和检索过程交互。
- 将服务信息与调用预算放入“模型与调用范围”，减少默认表单的信息负担。
- 新问答结果中的适配条件改为可读列表，避免直接展示数据结构。
- 增加导航横向收缩处理，防止第七个入口挤掉模型及语言控件。

## 接入与兼容

- 新组件与复盘控件隔离：助手 DOM ID 统一使用 `rag-` 前缀，选择器限定在助手工作区内。
- 新页面使用 `mission.css` 和局部 `research-workspace.css`，没有引入旧的 `assistant.css`。
- `/assistant` 自动跳转新版，保留 `job`、`case`、`whole`、`event` 等参数。
- 比赛案例内的教学链接直接指向新版工作区。
- 页面初始化识别研究视图，不再等待分析页初始化后才切换展示；不会因默认回放模式抢走研究视图。
- Agentic RAG 后端流程与预算未改变。本轮没有调用外部模型。

## 验证

- 浏览器实际检查新版页面及主题布局。
- 使用已标注的离线样例任务检查恢复结果、检索轨迹、引文展开和来源链接。
- 实际从助手切换到战术室，再返回助手，当前结果保留；浏览器未报告 JavaScript 错误。
- 旧链接带任务参数成功跳转新版并恢复任务。
- HTTP 检查确认旧链接保留案例、整套教学和任务参数；新版 HTML、JS、CSS 均返回 200。
- HTML ID 唯一性检查通过，未引入旧样式文件。
- 修改的前端脚本通过语法检查，服务端路由通过 Python 编译检查。

本轮是界面整合验收，不代表外部模型的战术判断质量已验证。窄屏规则已添加，未做完整移动端设备矩阵验收。
