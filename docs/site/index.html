■ Agent analysisAgent 分析

An analyst that shows its evidence会出示证据的 AI 分析师

The Agent never watches the demo raw. The server first builds an evidence packet from the parsed match: positions, utility, kills, economy, each with an ID. The Agent reads it with tools, checks the windows that matter, and submits findings that must cite those IDs. A local audit then removes anything the data does not support.Agent 不直接“看” demo。服务端先从解析结果生成证据包：站位、道具、击杀、经济，每条都有编号。Agent 用工具读取证据、核对关键时间窗，提交的每条发现都必须引用这些编号；随后本地审核会删掉数据不支持的结论。

■ Flight rules飞行守则

Privacy and trust隐私与可信度

RULE 1 · GO

Local by default默认本地

The server binds to 127.0.0.1, checks Host and Origin, and requires a session token for every write.服务只监听 127.0.0.1，校验 Host / Origin，所有写操作都需要会话令牌。

RULE 2 · GO

Your keys stay yours密钥留在本机

The Steam Web API key is stored locally and never sent back by the API.Steam API Key 保存在本地，接口不会把它返回。

RULE 3 · GO

No silent model calls不偷偷调用模型

The LLM runs only when you click, and each run has a call budget.只有点击后才调用 LLM，每次都有调用上限。

RULE 4 · GO

Honest outputs结果诚实

Model results are labelled, inferences are kept apart from observed facts, and validation reports include the failures.模型输出明确标注，推断与观测事实分开，验证报告包含失败案例。
