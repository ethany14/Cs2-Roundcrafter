## 一个具体变化

在比赛 2398755 第 18 回合、tick 169580（主体死亡前约 2 秒）的案例中，当前静态模型显示主体到四名存活敌人的目标射线均受阻。之后击杀主体的敌人处于近似视锥内，但射线仍受阻；这一片段前 5 秒没有采样到相关发现记录。

因此，不能仅凭观战知道敌人很近，就批评主体没有提前处理这个敌人。也不能反过来声称玩家完全不知道：更早信息、声音、语音和地图模型版本仍可能改变解释。

完整片段见 [局势证据报告](./49fabf21b1c26f10-169708-c419e90e5549-evidence.md)。它是本地程序生成的证据报告，不是本轮新的大模型判断。

## 仍未达到的能力

**目前还不能可靠判定某个决策正确或错误，也不能进行玩家决策评分。** 当前地图来自公开的 CS-NET 仓库资产，版本未与各场 demo 对齐；静态模型没有还原动态门、可破坏物或材质透明性。两条射线和近似视锥不能替代游戏实际可见性。

缺少完整声音、语音、队伍目标、导航路径、反应时间和武器准备状态。近似发现标记也不能证明玩家注意到了目标。因此程序明确保留 `can_score_decision=false`；允许带条件、带证据的调查，禁止把几何近似结果包装成可靠决策判断。

下一步需要用游戏内回放核对一小批可见/不可见场景，确认地图版本与动态遮挡，再完善信息历史和可行替代动作。新增资料也需要逐条核对视频和游戏内投法。本轮没有新发起外部大模型调用。

## 如何运行

在 CS2 工作区运行：

```powershell
# 建库、补地图/信息证据、输出本地 Markdown 报告（无 API 调用）
./start-review.ps1 -Build -Offline

# 已完成本地补充时，直接生成当前片段报告
./start-review.ps1 -Offline
```

新增实现位于 `backend/cs2_agent/geometry.py`、`perception.py`、`learning_resources.py`；资料卡位于 `experiments/knowledge/resources.json`。地图资产来源为 [CS-NET 固定版本](https://github.com/Gary2005/cs-net/blob/268dd2193c8a3d6e330c07dde5a851196c94eeaa/maps/optimized_obj_files/de_dust2.obj)，上游许可证副本保存在 `data/maps/upstream-LICENSE.txt`。
