# 回防／等待集合／保枪：首轮原型报告

日期：2026-10-13。本机解析与训练，无付费 API 调用。

## 结论

**已经建立可运行的条件场景、行为模型、Agent 查询接口和人工盲评材料；尚未训练出可靠的战术价值判断器。** 模型超过此次简单规则的行为分类表现，但历史模型未超过当前状态模型。三个战术候选的条件由规则编写，其合理性尚待人工评审，不能把行为概率当推荐概率。

## 数据与信息边界

77 个 demo、30 个系列、七张地图。下包后 2／8／14／20／26／32 秒采样 CT 生存玩家，得到 7723 个窗口，其中 4576 个有可用弱标签。保留原 19／5／6 系列划分；不是新比赛上的独立测试。

每个输入含 7 帧、覆盖 12 秒；逐帧自身状态、人数、队友部署距离、道具、闪光、声音范围候选和自身点亮的最近敌情。敌情记忆从本回合此前采样帧累计，过期后不以隐藏坐标刷新。普通 `player_sound` 使用事件半径，未接入枪声资源曲线和声学遮挡；声音比较使用当前历史帧的听者位置，存在最多约 2 秒的位置时间差。敌方装备、血量、隐蔽位置不进入输入。

**条件假设：下包 2 秒后，给 CT 提供包的真实坐标。** 这模拟明确报点，未证明原选手当时确实知道。此前历史帧中的包位置特征为零；该假设会限制向缺少报点的普通玩家场景迁移。

未建立区域导航图、经济跨回合规划、队内语音、动态门和有效烟火的战术可行性计算。模型使用距离代理而非可走路线；40 秒炸弹计时、250 单位/秒移动和 5/10 秒拆包在候选说明中是明确的场景假设，不是逐 demo 配置核验。不能据此断言一条路线必然赶得上。

## 弱标签的具体含义

- 向包点靠近至少 192 单位，或观察到开始拆包。
- 六秒后净位移不超过 128 单位，且到包距离变化不超过 96 单位。
- 到包距离增加至少 192 单位，且结束时距离至少 1200 单位。

第二类可能是架枪、交战、小范围活动，不能直接解释为等待队友；第三类也可能是绕路，不能直接解释为保枪。未使用回合输赢决定标签。未来六秒死亡、回合结束或轨迹不明确的记录不参与分类损失，因此分类测试子集有选择偏差。没有伪造人工评价。

## 训练与验证

每组 3 个种子，80 轮，按验证集 NLL 选检查点。当前组将当前状态重复输入同一 GRU，保持结构和参数量相同；历史组使用真实序列；无信息组去除声音和敌情字段。对照为训练先验与预先固定的人数／时间／支援距离规则。选模型只看验证集，选择结果为 current。

| 模型 | 弱标签准确率 | Macro F1 | NLL |
|---|---:|---:|---:|
| current | 65.0% | 0.590 | 0.814 |
| history | 63.8% | 0.577 | 0.847 |
| history_no_information | 63.6% | 0.589 | 0.837 |
| training_prior | 39.9% | 0.190 | 1.070 |
| rule | 42.6% | 0.401 | 1.764 |

分类测试共 868 个有标签窗口。置信度阈值仅用验证集选取，为 0.70；在有标签测试子集中保留 48.8% 的窗口，与弱标签一致率 80.0%。这是几何行为一致率，不是战术正确率，也没有包含被删失的 586 个测试窗口。

未对新比赛验证、未进行真人盲评、未在真实游戏中执行候选。指标以窗口统计，相关窗口不能当独立比赛；仅有六个测试系列，不宣称统计显著性。

九次训练与评估约 41.0 秒，PyTorch 峰值已分配显存 89.9 MiB；不含 demo 解析和驱动显存。

## 可以运行的部分

- AgentLoop 工具 `inspect_postplant_strategy(sample_index)` 返回证据、三种候选的条件／风险／对手回应检查及行为概率；未替换网页 A/B 决策模拟。
- `experiments/movement/predict_strategy.py` 可对注册样本或自带 7×26 历史输入执行 CPU 模型推理。
- `战术候选-人工盲评表.md` 和 `blind-review.json`：每图随机 3 个片段，共 21 个，没有未来标签和模型分数。每个片段允许其他方案与信息不足，不能用未来结果倒推评判。
- `rows.json` 是研究文件，含未来弱标签；不能整份传给决策 LLM。Agent 工具只输出白名单字段。

## 验证与复现

Node 因果测试覆盖未来／隐藏坐标、包位置披露边界、历史敌情与标签边界；Python 候选与已有环境边界测试 9 项通过。离线 CPU 与 GPU 集成推理对照 22 个样本，最大概率差 0.000201，最高概率类别全部一致；按 0.002 概率绝对差容差验证。系列隔离、21 份盲评数据不含未来标签、Agent 工具白名单均通过检查。初次使用 1e-6 的跨设备容差未通过，随后检查了更大的样本集合并记录实际差异。

在工作区根目录运行：

```powershell
$env:PYTHONPATH='backend'
.venv/Scripts/python.exe experiments/movement/run_strategy_extract.py
.venv/Scripts/python.exe experiments/movement/train_strategy.py
.venv/Scripts/python.exe experiments/movement/predict_strategy.py --sample-index 0 --output outputs/movement/strategy/prediction-example.json
.venv/Scripts/python.exe experiments/movement/report_strategy.py
node experiments/movement/strategy.test.cjs
```
