# CS2 全地图 Frozen Qwen 三组对照实验报告

日期：2026-10-13。全部计算在本机执行，无付费模型调用。

## 结论

在本轮固定的测试集上，A/B/C 的平均位移误差（ADE，越低越好）分别为 **63.09 / 69.59 / 68.91 游戏单位**。较强的简单基准“衰减匀速”为 **69.73**。

融合相对数字模型的样本加权误差增加 **9.23%**；Frozen Qwen 单支增加 **10.31%**。数字模型相对衰减匀速基准降低误差 **9.53%**。

以独立比赛为单位的配对比较：融合相对数字模型的平均 ADE 改善为 **-5.88**，比赛 bootstrap 95% 区间 **[-6.98, -4.88]**。测试只有 6 场，该区间仅是小样本探索性不确定性估计。

当前模板、池化、样本量与训练配置下，Qwen 单支和融合均未改善数字模型，融合在六场比赛上的配对区间也显示误差增加。应优先保留数字时序模型继续研究，不将这个结果外推为所有 LLM 方法无效。

本实验预测职业玩家真实后续位移，不判断该选择是否最优，也不模拟击杀、输赢或完整残局。

## 输入、标签与模型

- 2 秒历史，0.5 秒采样；预测未来 0.5、1、2 秒的 XY 位移，坐标以当前玩家朝向旋转。
- 三组获得完全相同的输入数值，统一保留三位小数。Qwen 输入为固定模板、同样的历史和当前上下文；没有增加自然语言战术解释或额外检索。
- 输入：自身相对轨迹/高度、朝向变化、俯仰、蹲下、闪光状态；血甲、阵营、时间、双方存活人数、下包计时、最近两名队友的相对位置。
- 不含玩家身份、绝对地图坐标、隐藏敌方位置、未来事件、胜负或目标轨迹。队友位置及计数假定可从队伍雷达/记分板获得，未完整复现个人感知与通讯。

| 组别 | 实现 | 可训练参数 |
|---|---|---:|
| A 数字时序模型 | 48 维 GRU + 当前上下文 + 预测头 | 12,902 |
| B Frozen Qwen + adapter | 冻结 Qwen3-4B，2560 维特征 → 64 维 adapter → 预测头 | 168,454 |
| C 融合模型 | GRU/上下文 + Qwen adapter，拼接后预测 | 180,902 |

- Qwen 主干不更新；最后一层输出按有效 token 做均值池化；不生成回答。缓存只提取一次。
- 三组训练参数量不同，因此本实验是实用管线比较，不是等参数量的架构因果消融。
- 共同设置：3 个随机种子 [7, 17, 29]、最多 100 epoch、batch=256、AdamW lr=0.001、weight_decay=0.01、梯度裁剪 5；loss 是三时点欧氏距离均值。
- Qwen 特征标准化只使用训练集统计；每个种子的最佳 epoch 只按验证 ADE 选；最终预测是三个种子的平均。测试结果未用于调参。

## 局限和下一步

1. 目前没有地图几何/导航/视线、敌人可见性历史、真实烟雾和穿墙伤害输入。不能据此检验地图空间理解，更不能用它直接判断玩家失误。
2. 标签是职业玩家实际走法；一次观测不覆盖其他合理选择。回归输出还可能平均多条路线而穿墙。下一阶段需要多候选轨迹及地图可达性过滤。
3. 只保留整个历史和未来窗口均存活、没有异常位移的片段，存在生存者选择偏差，不覆盖死亡风险结局。
4. 64 窗口/demo 是计算预算取舍，数据规模远小于完整提取集；“全部地图一起训练”不代表已经使用每一帧。
5. 只测试单一文本模板、冻结模型和池化方式，不能把结果泛化为所有 frozen LLM 或 LoRA 方法的结论。
6. 后续应先在验证集加入更充分的时序/地形输入，并做参数量匹配对照；扩容或调整后必须另留新比赛作确认测试。当前测试集已经打开。
7. 本轮结果没有自动接入网站推荐或 AgentLoop，也没有替换现有功能。实验产物可供之后集成。
