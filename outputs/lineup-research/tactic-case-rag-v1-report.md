# 战术案例检索与学习入口 v1

日期：2026-10-13

## 实际完成

- 将已完成的 demo 回合分析整理成本地案例索引。每个案例保留比赛、回合、阵营、原分析来源、demo 指纹、证据引用和可播放时间段。
- 只接受有效证据引用和有效播放区间；排除未完成分析，去重同一 demo 的重复案例。分析文件变化后，下次检索更新缓存。
- 网站新增“案例库”，支持关键词、地图和阵营筛选。每条案例可点击播放对应过程，支持跨比赛和回合跳转。
- “学习这套战术”展示该片段内真实道具事件、玩家行动证据、本地教学候选与待补字段。道具缺项可进入现有研究助手，预填查询需求。
- 复用现有道具研究和 Eregion AgentLoop。案例入口只预填需求，玩家点击开始才启动研究。
- 原有整套教学入口绑定固定 Nuke 模板，因此案例研究限制为同地图的单颗需求，避免套用旧模板的分工和时序。

## 事实、推断与检索范围

- 战术标题和解释仍标记为模型推断；不因为进入案例库就变成来源事实。
- demo 事件保留原事件编号、发生时间、玩家编号和道具类型。事件出现不能证明具体瞄点、投掷动作或教学方案可复现。
- 本地教学结果标记为未验证候选，保留原始来源和视频链接，不声称已经匹配投掷起点或战术用途。
- 当前检索采用本地关键词、中英文别名及中文片段匹配，不是向量语义检索，也没有让模型重新解释每条搜索结果。
- 此版本尚未把历史案例自动注入新回合分析。这样不会为每回合增加一次检索模型调用，也不会让旧解释覆盖新 demo 的证据。

## 未完成范围与限制

- 未进行新的联网道具研究，没有验证新的投法或游戏实投结果。
- 学习清单不是已验证的五人执行方案；目前逐项接入原有道具研究入口，尚未自动批量补齐全部教学。
- 关键词和别名匹配可能漏掉表达差异大的案例；教学候选可能用途不同，需要后续适配检查。
- 尚未加入向量检索，也未评估语义检索对命中率的提升。
- UI 美化按用户要求暂停，本轮只增加功能所需控件。
