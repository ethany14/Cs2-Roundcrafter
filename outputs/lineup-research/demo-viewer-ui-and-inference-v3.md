# Demo 回放 UI 与自由战术推断 v3

## 本轮完成

实际打开并播放了用户提供的 cs2.cam 回放，验证暂停、继续播放及时间推进。参考其地图优先、低对比度雷达、双方颜色、底部回合和事件时间轴、侧栏信息组织，调整了现有页面；没有复制其代码或比赛资产。

- 地图成为主画面，比赛上传收进菜单；回合按钮显示胜方颜色。
- 增加可点击的道具、击杀、下包时间刻度和最近击杀提示。
- 右栏切换战术解读与双方队员状态，展示真实 HP、当前武器与已有装备数据。
- 战术依据折叠展示，点击判断对应的片段可播放并高亮相关人员，结束时自动暂停。
- 继续复用 Eregion AgentLoop。允许 Agent 自拟战术名称、推断分工和目的，不再限定为预设规则名单，也不再要求每条重复“意图未确认”。
- 自由判断保留置信程度和字段证据引用核验；不存在的证据 ID 仍然拒绝。观察事实与 Agent 推断分开展示。

## 真实模型验证与范围

Dust2 第 1 回合使用原授权剩余的 2 次模型调用，得到五条自由推断，包括四长一中慢控打 A、首掉后补枪重组、中路牵制分工、火闪进点及守包。原始响应部分条目没有填写冗余的 custom 标记，初次提交因此被拒绝；修复为可根据自拟标题识别自由推断后，在本地重新校验原始模型输出并保存，未追加调用。原完成结果留有历史副本。

真实结果摘要：T 开局四长一中集结抢 A 大，首掉后降速重组，经中路补枪和火闪掩护从长坡进入 A 区下包，守包获胜。

位置、击杀、投掷事件、进入包点与下包时间来自现有 demo 解析；“牵制”“掩护”“重组”等是 Agent 对这些事实的解释。引用校验仅证明引用存在，不代表战术目的或道具效果已经由游戏事实证明。没有生成经济数据、道具作用范围或游戏实投结论。

其余三个试点沿用已有真实结果，本轮未重新调用模型。新规则适用于后续有授权预算的分析，不把旧缓存描述为已经重新推断。
