# 整套案例教学 v2：实施与真实验证

日期：2026-10-13

## 已交付

案例库 → 学习这套战术 → 自动补齐整套教学与逐人步骤 → 一键研究整套战术。

一次任务自动处理所选案例片段内全部己方道具事件，无需逐颗点击。支持当前可索引的 Nuke / Dust2 案例，不再套用固定 Nuke 教学模板。网站支持取消、显示总用量、通过任务链接刷新恢复结果。

工具先整理需求、本地检索、按查询去重，自动搜索 YouTube、Bilibili 和公开网页，读取候选原始来源及本地原视频。首次读取失败后尝试下一候选；相同来源不重复读取。各事件仍保留独立持有人、时间和需求，查询合并不代表投法等价。

现有 Eregion WorkspaceHost / AgentLoop 在来源收集后一次整理整队建议和教学文字提取，正常只需一次模型调用；最多两次，允许一次模型输出修正。没有新建聊天机器人，也没有修改核心 AgentLoop。

逐人结果包含原片段路线、道具生效、下包/拆包/阵亡事件、装备快照、道具使用次数、Agent 协同建议、证据编号和对应战术回放链接。保留没有投掷的队友。模型建议与 demo 事实分栏显示。

## 预算与取消

| 项目 | 整套共享上限 |
|---|---:|
| 搜索 | 8 次 |
| 页面或视频读取 | 16 次 |
| 模型 | 2 次 |
| 每次模型输出 | 4000 tokens |
| 模型输入保守预留 | 60000 |
| 网络阶段累计时间 | 240 秒 |
| 单次模型超时 | 最多 45 秒 |

搜索/读取计数表示应用工具操作，底层 HTTP 请求量另行记录；第三方命令内部 HTTP 次数可能未知，但已有重试和超时限制。缓存命中单独计数。任务恢复保留累计预算。取消后不再发起调用，已发出的模型/HTTP 请求可能持续到超时。

来源不足、未找到、不可访问、搜索不可用、不适配、预算耗尽分别保留。来源不足也返回全部需求及已有逐人记录，不会因为最后模型失败而丢弃整个结果。

## 证据和适配边界

- 搜索标题和摘要只用于发现线索。模型提取动作必须引用任务中实际读取的原文；逐字校验通过后才记录字段证据。
- 模型执行建议必须引用存在的证据编号，并且至少一条证据涉及对应玩家；要求覆盖全体玩家。引用校验不等于自动证明每个语义推断正确。
- 检查地图、阵营、道具、人数、动作标签、起点/目标、装备和时序；缺失字段保留未知，不能靠检索词填成来源事实。
- 片段起始装备不等于后续投掷时装备，可能存在拾取，不能据此误判不适配。
- 生效时间不是释放时间，片段内使用次数不是开局购买清单。游戏实投仍未验证。
- 教学候选不自动写成已验证投法；原视频可展示，即使没有坐标或字幕。
- 当前范围是所选战术案例的播放片段，不保证涵盖片段之前的全部准备道具。
