# Roundcraft — CS2 本地复盘原型

调研日期：2026-10-12（America/New_York）。当前版本 0.2.0，已加入独立 Agent 自动复盘，详见 `AGENT.md`。

## 启动

需要 Node.js 22.19 或更新版本。在本文件所在目录执行：

```powershell
npm ci
npm start
```

打开 http://127.0.0.1:8787 。也可以在 PowerShell 中执行 `./start.ps1`。占用端口时可设置 `$env:PORT=8788` 后启动。

## 已实现

- 导入不超过 512 MB 的未压缩 CS2 `.dem`，在本机独立进程中解析。
- 逐玩家、逐回合筛选三类片段：队友致盲、雷火对敌伤害、死亡前仍持有道具。
- 每个片段关联 tick、事件和位置朝向快照；位置图不包含地图几何和视线判定。
- 保存人工复盘判断、笔记、训练项，勾选练习完成。
- 同地图同玩家的跨比赛原始事件数量对比。不会据此宣称训练有效。
- 导入后 Agent 自动检查片段和回合，交付总结、最多 3 个训练重点及引用。
- 调用预算、任务去重、停止与失败状态、AI 报告导出。

使用“查看真实测试样例”可以直接体验。样例来自解析器仓库公开的真实测试 demo，经本原型解析并匿名化；不是合成的比赛评分，也不是职业比赛基准。

## 实现口径

- 致盲：持续至少 0.5 秒，按当时队伍号区分敌友，排除自闪；单位为受影响玩家事件，不是投掷颗数。
- 道具伤害：对敌 HE / inferno / molotov / incendiary 的逐次 health damage，单次限制在 0–100；卡片阈值 20，汇总包括低于阈值的伤害。不是精确的伤害贡献评级。
- 道具死亡：只使用死亡前一 tick 且仍存活的背包快照。缺失时不做该判断。
- 排除已标注热身事件；可用时依据 freeze_end / round_end 约束片段。异常或截断 demo 可能缺少部分回合。
- tick 速率通过原始 game_time 差分估计；无法稳定估计时只输出 tick。
- 在全局快照中看到敌人，不等于玩家当时看到敌人。准星射线只是 yaw 朝向，未提供“正确准星”或自动枪法评分。

## 数据与成本

独立 Node.js Agent 从项目根目录 `.env` 读取模型服务配置。无需 GPU 或模型训练；云端模型会产生推理费用。不依赖 Eregion 工作区。源码 ZIP 单独解压后在解压目录创建 `.env`。

服务只监听 `127.0.0.1`。原始上传副本在任务结束后删除；异常强制关机可能留下 `.upload`，下次可手动删除。分析报告保存在 `data/`，AI 状态和结果在 `data/reviews/`。笔记与训练项保存在浏览器 localStorage；请导出备份（本版尚无备份导入）。原始 demo 不上传；云端模型会收到匿名化结构化比赛摘要及所需事件。

## 验证

0.2.0 的 18 项本地测试覆盖解析规则，以及 Agent 伪造引用、玩家归属、匿名化、截断响应、一次预算内精简恢复、配置缺失与任务去重。真实 API 联调记录见 `agent-verification.json`。

其中解析器的 8 项检查全部通过，覆盖热身、自闪、敌友区分、死亡前背包、伤害统计和样例证据一致性。另通过公开真实 test_demo.dem 验证了完整导入流程：约 60.6 MB、10 名玩家、10 个可观测回合、47 个候选片段，本机本次全流程约 1.2 秒；这不是其他比赛的性能承诺。结果见 `verification.json`。

浏览器实测通过：真实样例加载、队友致盲筛选、保存复盘判断、加入训练列表、刷新后保留笔记和训练项；检查时未发现页面控制台警告或错误。保留了一条标注“样例复盘”的示例笔记与训练项，方便体验。

尚未验证所有 CS2 demo 版本；错误会明确提示，不以假数据替代。
